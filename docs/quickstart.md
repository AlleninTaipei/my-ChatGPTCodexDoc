# Quickstart

Start using ChatGPT on the web or in the desktop app.

## Where to use ChatGPT

Use ChatGPT across different surfaces, including the ChatGPT desktop app and ChatGPT on the web. Choose the option that fits your work.

Desktop app: Work across projects, local files, and long-running tasks. (Recommended)

Web (chatgpt.com): Work on complex tasks uninterrupted in the cloud. No installation required.

If you're a developer and want to use Codex in your terminal or code editor, try Codex CLI or the Codex IDE extension.

## Setup

### Desktop Setup

1. Install the ChatGPT desktop app

   Choose the version for your operating system (Windows or macOS).

2. Open the ChatGPT desktop app and sign in

   Open the app, then sign in with your ChatGPT account. You may also use Codex with an API key (some features might not be available).

3. Select where ChatGPT should work

   Start a task, create a project, or open a folder. ChatGPT can read and modify files in the folder you choose.

4. Start your task

   - For research, analysis, or deliverables (documents, presentations, spreadsheets, Sites): select ChatGPT Work
   - For software development with codebase context: select Codex
   - For quick questions: open Chat separately

5. Send your first message

   Describe your goal and add any files or context ChatGPT needs.

### Web Setup

1. Open ChatGPT and sign in

   Go to chatgpt.com and sign in with your ChatGPT account.

2. Start your task

   - Select Chat to ask questions and explore ideas conversationally
   - Select Work to research, analyze, and create finished work

3. Select where ChatGPT should work

   Start a chat or select a project.

4. Send your first message

   Describe your goal and add any files or context ChatGPT needs.
