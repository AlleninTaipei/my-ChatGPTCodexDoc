# What's new

A weekly digest of ChatGPT and Codex features that can change how you work.

This weekly digest highlights ChatGPT and Codex features that can change how you work, with examples and links to learn more. For every versioned update, bug fix, and minor improvement, see the Codex changelog.

## July 6-10, 2026

### Take on ambitious work with ChatGPT Work

ChatGPT Work is an agent that "can gather context from your files and plugins, take action across workflows, and create reviewable documents." Powered by GPT-5.6, it breaks goals into steps and works for extended periods while you monitor progress and approve actions.

Scheduled tasks automate workflows when you're away by running once, on a schedule, during specific events, or while monitoring for changes.

### Choose the right GPT-5.6 model

Three GPT-5.6 models are available across ChatGPT Work, the desktop app, Codex CLI, and IDE extension. Sol handles complex coding and security work; Terra balances capability and cost for everyday tasks; Luna offers the fastest, lowest cost option. The default Power setting uses Sol with medium reasoning.

### Use Codex in the ChatGPT desktop app

As of July 9, Codex merges into the new ChatGPT desktop app for macOS and Windows. Codex maintains its dedicated coding experience with inline editing, pull request review in the side panel, faster Computer Use powered by GPT-5.6, and multi repository projects.

## June 15-19, 2026

### Turn demonstrated workflows into reusable skills

Record & Replay lets you demonstrate workflows on macOS and convert them into reusable skills. This feature works for repetitive tasks easier to demonstrate than describe, then you refine and replay the generated skill with new inputs.

### Continue a task on another host

Task handoff moves a task and its Git state between your local computer and a connected remote host. Codex creates or reuses a worktree on the destination and transfers the task.

### Browse and review workspaces from iOS

In the ChatGPT mobile app, Remote added a workspace file browser, directory picker for new tasks, expandable diff controls, and per task MCP approval choices.

## June 8-12, 2026

### Debug web apps with Browser Developer mode

Developer mode gives Codex controlled access to Chrome DevTools Protocol capabilities in Chrome and the built in browser. Codex can inspect network traffic, console output, runtime errors, and page state while debugging your app.

Browser use is now "up to twice as fast because CDP and DOM snapshot optimizations reduce browser round trips."

### Bring your setup to Codex

New migration flows import supported setup from other coding agents during onboarding. The Codex app added `/init` for creating project instructions, improved plugin management and browser diagnostics.

### Set up Codex tasks from iOS

Remote on iOS can now choose a branch, create a worktree, run environment setup scripts, manage goals, and add inline review comments.

## June 1-5, 2026

### Build and deploy websites with Sites

Sites lets ChatGPT create, save, deploy, and inspect websites, dashboards, internal tools, web apps, and games hosted by OpenAI. Sites has a dedicated entry point where you can return to projects and manage hosted environment values.

### Use Codex with Amazon Bedrock

Codex now works with Amazon Bedrock for local workflows with AWS managed authentication, account controls, and billing. Remote on iOS added optional in app lock, follow up behavior settings, and SSH connections to Windows machines.

## May 25-29, 2026

### Use Windows apps and control Codex remotely

Computer use added support for seeing, clicking, and typing in Windows desktop apps. On Windows, Codex uses the active desktop and takes over the foreground while the task runs. Remote connections also support Windows.

Remote on iOS added Spotlight and Shortcuts entry points, archived task browsing, and options to save or copy rendered images.

## May 18-22, 2026

### Give Codex context from any Mac app with Appshots

Appshots send the frontmost app window to Codex with a screenshot and available text when you press both Command keys. Codex receives working context from design tools, dashboards, and documents without requiring manual copy and paste.

### Follow long running goals

Goal mode became generally available in the Codex app, IDE extension, and CLI for objectives spanning hours or days. Locked use lets Codex continue approved computer use work after a Mac locks, including through Remote in the ChatGPT mobile app.

## May 11-15, 2026

### Continue desktop work from mobile

In the ChatGPT mobile app, Remote connects to a Mac running the ChatGPT desktop app. Work runs on the connected host, keeping your projects, files, credentials, plugins, skills, and configuration available when continuing from your phone.

### Automate trusted workflows

Hooks reached general availability for running custom commands at key points in the agent lifecycle. ChatGPT Enterprise admins can enable Codex access tokens for trusted scripts, schedulers, and private CI runners.

## May 4-8, 2026

### Work across browser tabs with the Chrome extension

The Chrome extension can work in parallel across tabs in the background without taking over your browser. You control which websites Codex can use, making it practical to combine research, data entry, and verification across web apps in one task.

The Codex app added dictation cleanup and a custom dictionary for names, file paths, and code symbols. ChatGPT Enterprise workspace owners can allow members to create Codex access tokens for trusted, non interactive workflows.

## April 20-24, 2026

### Use GPT-5.5 for complex work

GPT-5.5 arrived in Codex as the recommended model for most tasks, with strengths across "implementation, debugging, testing, computer use, research, and finished knowledge work outputs."

### Let Codex operate the browser and review approvals

Computer Use in the built in browser lets Codex click through local development servers to reproduce issues and verify fixes. Eligible approval requests can go through automatic approval review.

## April 13-17, 2026

### Preview and operate work in one place

The built in browser added live previews and page comments, while Computer Use let Codex see and operate macOS apps. This integration made visual implementation and end to end verification part of the same task.

### Start with a task and keep it moving

Standalone tasks made it possible to begin without choosing a project folder. The same release added scheduled work from a task, pull request context, and richer file previews.

## April 6-10, 2026

### Review and ship pull requests in the app

The review experience added collapsible inline comments, inline and detached review modes, and clearer Git and source context. Pull request activity moved into the app alongside workspace file tabs.

## March 23-27, 2026

### Package workflows as plugins

Plugins launched as "installable bundles of skills, connectors, and MCP servers." They made complete workflows easier to discover, install, and share. Redesigned plugin and skill pages clarified their contents and status. Search for past tasks also arrived that week.

## March 16-20, 2026

### Branch earlier and choose tools from the composer

You could fork a task from an earlier message, making it easier to explore new approaches. Model and reasoning commands became available while drafting, and GPT-5.4 mini added a faster option for lighter tasks.

## March 9-13, 2026

### Schedule work with the right environment

Scheduled tasks could run locally or in a worktree with explicit model and reasoning levels. Reusable templates made common tasks faster to configure, and custom themes personalized the workspace.

### Let Codex inspect terminal output

Codex learned to read the integrated terminal for the current task, inspecting running development servers or build output directly.

## March 2-6, 2026

### Run Codex natively on Windows

The Codex app launched on Windows with native PowerShell and sandbox support, plus worktrees, scheduled tasks, and skills.

### Move tasks between Local and Worktree

Local and Worktree handoff made it possible to move an active task while preserving context. GPT-5.4 arrived in Codex for coding, computer use, and longer context workflows.

## February 9-13, 2026

### Iterate in real time and branch an approach

GPT-5.3-Codex-Spark entered research preview as a near instant model for real time coding iteration. The app added conversation forking and a floating, always on top task window.

## February 2-6, 2026

### The Codex app launches on macOS

The Codex app launched as a desktop workspace with parallel project chats, built in Git review, worktrees, skills, scheduled tasks, and voice dictation.

### Steer active work and add files

Mid turn steering made it possible to redirect Codex without stopping an active response. File attachments expanded beyond images.
