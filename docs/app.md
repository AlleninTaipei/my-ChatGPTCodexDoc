# ChatGPT Desktop App

## Your command center for complex work

Run projects in parallel, work with files, use your computer, and keep long running work moving from one desktop workspace.

## Artifacts

### 01 Keep every task in view

Move between projects and long running work without losing context.

### 02 Create and inspect real outputs

Open documents, spreadsheets, images, and other files in the same workspace.

### 03 Work across your tools

Use the browser, desktop apps, and plugins, or schedule work from a task.

## Quickstart: Get started with the desktop app

Install ChatGPT, sign in, choose where to work, and send your first message.

### 1. Install the ChatGPT desktop app

Download ChatGPT for Windows or macOS.

### 2. Open ChatGPT and sign in

Open the app, then sign in with your ChatGPT account.

### 3. Choose where to work

Start a task, create a project, or open a folder. ChatGPT can use the files and context in the location you choose.

### 4. Send your first message

Choose Chat, Work, or Codex for the task, then describe the result you want and add any files or context ChatGPT needs.

## Use the ChatGPT desktop app when…

- Coordinate several projects: Keep parallel work visible and move between tasks quickly.
- Create and review files: Build finished work and inspect it without leaving ChatGPT.
- Use the browser and your computer: Give ChatGPT access to the tools a task requires.
- Schedule recurring work: Create a standalone scheduled task or schedule work from an existing task.
