Get started with Work

Work 是什麼

Work 是把實際工作委派給 ChatGPT 的一種方式。當你想要一個答案, 解釋, 腦力激盪或短篇草稿時使用 Chat；當你想要 ChatGPT 完成具有明確結果的任務, 例如簡報, 分析, 週期性更新, 工作流程或可審閱使用的檔案時, 使用 Work。

Work 可以使用你的檔案, 外掛與已核准的工具來擷取資訊, 建立成品, 執行工作流程並完成可供審閱的工作。你可以追蹤進度, 回答問題, 調整方向, 並核准重要動作。桌面應用程式中, Work 還能使用本機檔案, 應用程式與瀏覽器。

先嘗試哪些任務

先確認 ChatGPT 中已選擇 Work, 再挑選你的第一項任務, 好的任務需要明確的結果, 少量來源素材, 以及可供審閱的產出。

選擇使用情境: 建立簡報 建立比較試算表 設定週期性更新

把筆記, 文件, 研究或會議素材轉換成結構化的簡報。

範例提示
Review the attached source materials and create an eight slide presentation for [audience]. Focus on the main themes, include supporting evidence, and flag anything that needs human review.

把筆記, 檔案或研究轉換成能比較選項並協助決策的試算表。

範例提示
Create a spreadsheet comparing the options for [decision]. Include the most important criteria, score each option, flag risks or missing information, and add a summary tab with a recommendation and next steps.

使用排程任務讓 Work 隨時間重複, 監控或更新某項工作。

範例提示
Every Monday morning, review new updates from @Slack and @Google Drive for [project]. Refresh the meeting agenda with decisions, blockers, owners, and open questions.

Prompting

權限如何運作

Sandbox
